# 운영 가드레일

- 리뷰·구현·실행·commit·push·배포 권한을 분리한다.
- revision, 환경, 실행 명령과 관찰 범위를 기록한다.
- 요구사항, 소스 추적, 실행 확인과 추정을 구별한다.
- 기존 사용자 변경을 덮어쓰거나 무관한 테스트를 약화하지 않는다.
- mock 수, assertion 수, fixture 크기와 coverage 비율에 보편 수치 기준을 두지 않는다.
- 특정 테스트 스타일, 아키텍처나 test pyramid를 맥락 없이 강제하지 않는다.
- 테스트를 실행하지 않았다면 통과했다고 보고하지 않는다.
- PASS, FAIL, 미검증과 해당 없음을 구별한다.
- 테스트가 확인하지 못한 실제 외부 동작과 환경 차이를 명시한다.
